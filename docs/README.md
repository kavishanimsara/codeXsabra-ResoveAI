## 🏛️ System Design Principles

1. **Context Compression**: Avoid dumping massive unformatted datasets directly into LLM prompts. Filter, group, and calculate mathematical facts using Pandas first.
2. **Explainability**: Every decision generated by the system must include a 4-stage explainable audit trail (`DETECT`, `ANALYZE`, `DECIDE`, `ACT`).
3. **Monetary Precision**: All financial amounts must be formatted in Sri Lankan Rupees (`LKR` / `Rs.`) to maintain local currency context.
4. **Resilient Adapter Pattern**: Frontend services must gracefully handle offline/standalone fallback modes when API backends are starting up or unreachable.
